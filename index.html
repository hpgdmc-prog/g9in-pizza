📲 앱으로 설치 (PC · 모바일)

이 화면이 웹 주소(http/https)로 열려 있을 때만 설치 버튼과 브라우저의 설치 안내가 나타납니다. 컴퓨터에서 파일을 더블클릭해서 연 상태(file://)라면 먼저 이 폴더를 웹으로 접속할 수 있게 해두어야 해요.

PC (Chrome · Edge) — 주소창 오른쪽의 설치 아이콘(⊕) 클릭 → 설치
iPhone (Safari) — 하단 공유 버튼 ⬆️ → "홈 화면에 추가"
Android (Chrome) — 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"

☁️ 실시간 동기화 (PC · 모바일 자동 연동)

현재는 원부자재·구입처·레시피·가맹점·발주·밀키트 판매(주문·고객·메뉴·비용) 등 앱의 모든 데이터가 기기마다 따로 저장됩니다. 아래에 무료 Firebase 프로젝트를 연결하면, 한 기기에서 저장한 내용이 다른 기기(PC·휴대폰 등)에 자동으로 실시간 반영됩니다.

① Firestore 데이터베이스 만들기 — console.firebase.google.com 접속 → 새 프로젝트 만들기(무료) → 왼쪽 메뉴에서 Firestore Database → 데이터베이스 만들기 → 테스트 모드에서 시작 선택
② 웹 앱 등록 & 설정값 복사 — 프로젝트 개요 화면에서 </> (웹) 아이콘 클릭 → 앱 닉네임 입력 후 등록 → 화면에 나오는 firebaseConfig 값들을 아래에 그대로 입력

⚠️ 이미 다른 기기에서 연동해두셨다면, 같은 값을 이 기기에도 입력해야 같은 데이터를 공유합니다. 처음 연결하는 기기의 로컬 데이터는 이미 저장된 클라우드 데이터로 대체될 수 있으니, 먼저 데이터 백업을 받아두는 것을 권장합니다.

💾 데이터 · 새로고침

※ 화면 새로고침은 최신 저장 데이터를 다시 불러옵니다. 전체 데이터 초기화는 이 기기에 저장된 모든 정보(재료·레시피·발주·밀키트 주문·고객 등)를 삭제하며 되돌릴 수 없으니, 먼저 백업 후 진행하세요.
※ 이 앱은 기기·브라우저마다 데이터가 따로 저장됩니다(자동 동기화 없음). 다른 기기에서 입력한 내용을 반영하려면, 그 기기에서 "전체 데이터 백업"으로 받은 파일을 이 기기에서 "백업 불러오기"로 열어주세요 (불러오면 이 기기의 기존 데이터는 덮어써집니다).
